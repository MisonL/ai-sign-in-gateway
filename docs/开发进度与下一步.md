- `design/login.png` 登录页新版 UI 已完成。
- 已按 `design/overview.png`、`design/session.png`、`design/sites.png`、`design/site-edit.png`、`design/site-edit-o.png` 启动多 subagent 并行 UI 开发并整合：
  - 网关监控 / Overview 页已改为暗色科技总览：顶部状态条、渐变指标、时间段消耗、实时调用、路由池状态与策略统计。
  - AI 对话页已重排为工作台结构：顶部任务条、模型选择、左侧配置、右侧网格背景对话区、消息气泡与输入区。
  - 站点列表已改为设计稿风格：深色玻璃页面、筛选搜索区、紧凑表格、状态标签、套餐/余额/操作区展示。
  - 站点编辑已由 drawer 改为设计稿弹窗：字段分组、暗色玻璃卡片、素材插画、滚动主体与底部操作栏。
  - 登录页移动端已修复 `100vh + overflow:hidden` 裁切风险，改为 `100dvh` 最小高度与可滚动布局。
- 网关并发额度逻辑已调整：单路由满额时优先转移到未满额路由；当所有路由均满额时，不把满额视为硬上限，继续按路由优先权选择。
- 网关已支持“模型精准转发”：
  - 路由新增 `supported_models`。
  - 请求带 `model` 时，先按 `route_type` 分流，再按 `supported_models` 精确过滤。
  - 若存在精确匹配，仅使用精确匹配路由。
  - 若无精确匹配，直接返回模型不支持，不再回退到未声明模型能力的路由。
- 路由探测在 Codex/OpenAI 兼容 `/models` 成功但返回空列表时，会默认写入 `gpt-5.4,gpt-5.5`，避免探测结果和支持模型编辑状态不一致。
- 验证与对话页已改为底部控制区：站点、模型、图片比例、宽高、清空会话和输入框集中在底部；左侧配置栏已移除。
- 图片生成尺寸支持 `1:1`、`3:4`、`4:3`、`16:9`、`9:16` 快捷比例；选择比例会锁定，手动输入匹配比例只做识别不自动锁定。
