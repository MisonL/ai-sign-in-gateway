# 使用指南

本页面向已启动爱签网关的使用者，说明日常操作路径。

## 页面概览

| 页面 | 说明 |
|---|---|
| `总览` | 查看站点总量、可用状态、余额汇总、最近签到和异常站点。 |
| `站点中心` | 维护站点、分组、插件配置、连通测试、签到、余额探测、API Key 和邀请码。 |
| `网关中心` | 查看网关概览、近 1 分钟趋势、路由池、策略配置、路由历史和最近请求。 |
| `验证与对话` | 选择站点后读取模型列表，用真实模型执行对话、参考图输入或图片生成验证。 |
| `设置` | 管理员账号、签到计划、网关策略等系统设置。 |

## 首次初始化

1. 打开服务地址。
2. 使用默认管理员或环境变量初始化的管理员登录。
3. 进入 `设置 -> 账号与密码` 修改管理员账号密码。
4. 进入 `网关中心 -> 网关策略` 设置网关 API Key。
5. 进入 `站点中心` 添加站点。
6. 对站点执行 `测试连接`、`余额`、`API Key 同步`。
7. 按需要创建分组。
8. 在 `设置` 中开启定时签到。
9. 进入 `验证与对话`，在底部输入区上方选择站点和模型，做对话或图片生成验证。
10. 使用 `/api/gateway` 作为统一模型请求入口。

## 站点管理

进入 `站点中心`，点击 `新增站点`。

常用字段：

| 字段 | 说明 |
|---|---|
| `名称` | 便于识别的站点名。 |
| `站点地址` | 站点首页或 API 根地址。 |
| `插件` | 决定登录、签到、余额和 API Key 同步方式。 |
| `分组` | 可多选，用于站点筛选和网关按组路由。 |
| `启用` | 停用后不参与签到和网关路由。 |

站点列表中的站点名称旁有新标签页打开图标，可直接打开站点。

## 分组管理

分组用于两个场景：

- 站点列表筛选和归类。
- 网关请求通过 `?group=<分组>` 只使用某组路由。

站点可归属多个分组。分组管理会维护分组目录，并同步处理站点和路由中的分组名称。

## 签到

单站点签到：

1. 在 `站点中心` 找到站点。
2. 点击操作列中的 `签到`。

批量签到：

1. 在站点表左侧勾选可签到站点。
2. 点击 `签到选中`。

定时签到：

1. 进入 `设置` 或站点中心的签到配置入口。
2. 配置定时签到开关、每日运行时间、时区、并发站点数、站点间隔秒数、重试次数、请求超时。
3. 按需设置是否只执行启用站点。

站点的 `可签到` 状态：

| 状态 | 含义 |
|---|---|
| `可以` | 参与批量签到和定时签到。 |
| `禁止` | 不参与批量签到和定时签到；列表中也不会显示该站点的签到状态。 |

## API Key、余额和邀请

支持的站点可执行：

| 操作 | 说明 |
|---|---|
| `API Key` | 查看或同步站点 API Key 列表。 |
| `余额` | 探测站点余额或路由余额。 |
| `邀请` | 读取邀请链接和邀请码，支持复制。 |

公开邀请码列表显示在登录页，只有已启用且有邀请信息的站点会展示。

## 验证与对话

`验证与对话` 是统一的模型连通性验证入口：

1. 在底部输入区上方选择已保存站点。
2. 系统读取该站点保存的 API Key、请求 API URL 和路由类型，自动请求模型列表。
3. 在同一控制行选择模型。
4. 输入消息发送。

普通对话模型走 OpenAI 兼容 `/chat/completions`。`gpt-image-*`、`dall-e*`、`imagen` 等图片模型走图片生成/编辑接口。

图片模型支持 `1:1`、`3:4`、`4:3`、`16:9`、`9:16` 快捷比例和自定义宽高；选择比例会设置最小 100 基准尺寸并锁定比例，解锁后手动输入会自动识别常见比例但不会重新锁定。

只有图片模型可以添加参考图；普通对话模型会阻止参考图输入，避免把图片发给不支持图片输入的上游。

## 网关中心

常见操作：

| 操作 | 说明 |
|---|---|
| `同步路由` | 从站点凭证和 API Key 列表生成路由。 |
| `测试` | 测试单条路由模型接口是否可用。 |
| `余额` | 探测该路由关联站点余额。 |
| `历史` | 查看该路由的请求历史。 |
| `熔断重置` | 将打开的熔断恢复为可探测状态。 |
| `启用/停用` | 控制路由是否参与网关调度。 |
| `类型` | 手动指定 Claude、GPT/Codex 或 Gemini 路由类型。 |

## 请求历史和趋势

网关中心包含：

- `近 1 分钟趋势`：20 根柱，每根约 3 秒聚合，展示成功、失败、流式、无请求。
- `路由历史`：每个路由的最近请求列表。
- `最近请求`：全局最近网关请求。
- `24h 概览`：请求数、成功率、延迟、流式成功率等。

日志中常见字段：

- 状态码。
- 成功或失败。
- 延迟。
- 策略。
- 路由标签。
- 失败原因。
- 是否流式。
